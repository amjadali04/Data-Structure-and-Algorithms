# Data Structures and Algorithms (DSA)

This repository documents my journey of learning and practicing Data Structures and Algorithms using C++.

## Learning Roadmap

### Phase 1: C++ Fundamentals Revision
- Variables and Data Types
- Operators and Conditions
- Loops
- Functions
- Recursion

### Phase 2: Data Structures
- Arrays
- Strings
- Linked Lists
- Stacks
- Queues
- Trees
- Hash Tables
- Heaps

### Phase 3: Algorithms
- Searching
- Sorting
- Recursion and Backtracking
- Greedy Algorithms
- Graph Algorithms
- Dynamic Programming

## Purpose

- Build strong problem-solving skills.
- Understand DSA concepts and their implementation.
- Practice writing clean and efficient C++ code.
- Analyze algorithm time and space complexity.

*Consistency over perfection. Learning DSA one concept at a time.*
